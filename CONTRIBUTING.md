# Contributing

Use Node.js 24+. No npm install is required for browser runtime or tests.

```sh
npm test
npm start
npm run release:source
```

Explain user-visible changes and add regression tests. Use synthetic fixtures;
never commit keys, runtime databases, personal prompts or local paths.

Translate new UI copy in all three dictionaries. Preserve keyboard access,
reduced motion and narrow-screen layouts. Provider tests must use mocks, not
billable requests. Outbound integrations need explicit consent and disclosure.

Update the source allowlist when adding a release file; never replace it with
recursive workspace copying. Contributions are under MIT. See SECURITY.md for
sensitive reports.
